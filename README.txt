WIRE TO FIRE — WEBSITE STARTER

Files:
- index.html: website content and structure
- style.css: dark futuristic, mobile-friendly design
- script.js: mobile navigation menu
- resources/: put downloadable files here

PREVIEW ON YOUR COMPUTER
1. Extract wire_to_fire_website.zip.
2. Open the extracted folder.
3. Double-click index.html to preview it in a browser.
4. For a better local preview, open the folder in VS Code and use the Live Server extension.

CUSTOMIZE THE WEBSITE
1. Open index.html in VS Code.
2. Replace each https://www.instagram.com/wire_to_fire/ placeholder with the exact URL of the matching Instagram Reel.
3. Update the headings, descriptions and links to match your videos.
4. Create a folder named resources (if it is not present) and add your own files.
5. In index.html, make sure the download link paths match your filenames. Example: resources/esp32-guide.pdf.
6. Do not upload private files, passwords, API keys or personal information.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a new PUBLIC repository named wire-to-fire-website.
3. Upload index.html, style.css, script.js and the resources folder contents (if any) to the repository root.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the deployment to finish. Your site address will usually look like:
   https://YOUR-GITHUB-USERNAME.github.io/wire-to-fire-website/
8. Open the address on your phone and test all links and downloads.

ALTERNATIVE: NETLIFY
You can also sign in at https://app.netlify.com/ and use its manual deploy / drag-and-drop option to deploy the extracted website folder. Follow the current instructions shown by Netlify.

INSTAGRAM
- Add the published website URL to your Instagram profile: Edit profile → Links → Add external link.
- In Reel comments, write: “Full resources: link in bio.”
- Instagram comments generally do not make website URLs clickable, so the bio link is the more reliable option.

IMPORTANT
- The Instagram links currently point to the profile, not specific Reels. Replace them with your actual Reel URLs.
- The PDF and ZIP download links are placeholders until you add those files.
- GitHub Pages public repositories are public. Only upload files you intend to share publicly.
